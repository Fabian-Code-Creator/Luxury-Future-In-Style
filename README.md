# LUXE ESTATES

A responsive, dependency-free luxury property website built with semantic HTML, CSS and browser JavaScript.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server, for example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included pages and interactions

- `index.html` — editorial homepage, property search, featured collection, category links, about, contact and newsletter.
- `properties.html` — filterable and sortable sample listings with grid/list presentation.
- `property.html?id=<property-id>` — reusable details page with image gallery and related residences.
- `legal.html` — clearly labelled demonstration placeholders for privacy and terms.
- `properties.js` — central demonstration listing data.

Favourites are saved in browser local storage. Enquiry and newsletter forms validate input but intentionally do not send or store it. All property details, prices, testimonials and contact information are demonstration content and must be replaced or verified before a production launch. The Unsplash photographs and Google Fonts require an internet connection.
